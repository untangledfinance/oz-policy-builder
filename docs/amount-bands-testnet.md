# Disjoint Blend amount bands — TESTNET proof

The disposable fixture uses one fresh Prime, one deterministic stateless adapter,
one custody wallet, one agent and one Blend pool. All six policies are generated by
`statelessBlendPolicies` from the SDK, installed unchanged and bound to the adapter.

| Supply amount (XLM) | Base units | Root policy |
| --- | --- | --- |
| Above zero and below 2 | `1 <= amount < 20000000` | Agent only |
| Exactly 2 | `amount = 20000000` | Neither band permits it |
| Above 2 | `20000001 <= amount < 2^127` | Agent + owner, pinned threshold 2 |

`2^127` is an exclusive SDK sentinel for the positive i128 domain. The high-band
root and child predicates omit an upper-bound policy comparison; protocol, balance
and allowance limits still apply. The root uses `gte(min)`, and children use the
integer-equivalent `gt(min - 1)`.

The high band uses the owner as the second approver. Its three context rules have
separate IDs from the low band; the pinned threshold policy is attached only to the
high root. A separate disposable cosigner key is generated but has no policy role.

The proof invokes the actual SDK `connectExecutionLane`/`supply` and production app
`loadCosignRequest`/`verifyExecutionCosign`/`continueCosign` modules against live
TESTNET. The continuation uses a local owner `PrimeSigner`. Browser wallet
interaction, wallet prompts and browser routing are **not proven** by this run.

Evidence is in [amount-bands-testnet.json](./amount-bands-testnet.json), including
public contract addresses, canonical predicate hashes, rule IDs, ledger receipts,
assertion results and final balances. Private keys and the transferable continuation
payload are stored only in the mode-0600 private state file outside the repository.
No mainnet transactions or Rust contract changes are involved.

Both live transfers succeeded and their receipts were independently re-read:

| production app owner co-sign high-band Blend supply | SUCCESS | 4707954 | [bf94709dda46…](https://stellar.expert/explorer/testnet/tx/bf94709dda46d4e9177593d3c4bd783af02543f1b16a854649591e42d2a95a54) |

Exactly 2 XLM was refused by SDK discovery without any state or source-sequence
change. With every required signer cryptographically authorized, enforcing RPC
simulation rejected 2.1 XLM through the low root, exactly 2 XLM through each root,
and 0.1 XLM through the high root. Every denial reached interpreter
`ArgMismatch #100`; none depended on missing signatures.

The high request produced a self-contained co-sign link with only the agent signed
and owner missing. Its partial authorization could not execute. Production app
continuation added the owner approvals and broadcast the transaction. Owner paid
the final transaction fee, in addition to supplying the custody assets.

Cleanup withdrew all Blend supply and revoked Prime's allowance. Fresh final reads
confirmed zero supply shares, zero Prime/adapter token balances and zero allowances
to Prime and adapter.

## Reproduce

From this repository with Bun installed and sibling SDK/app source checkouts:

```sh
export PRIME_SDK_ROOT=/path/to/prime-sdk
export PRIME_APP_ROOT=/path/to/octogear-app
export PRIME_STATE=/private/path/fresh-amount-bands-testnet.json
export VITE_STELLAR_NETWORK=testnet
PRIME_PROOF_PHASE=provision bun scripts/verify-amount-bands-testnet.ts
PRIME_PROOF_PHASE=prove bun scripts/verify-amount-bands-testnet.ts
PRIME_PROOF_PHASE=verify bun scripts/verify-amount-bands-testnet.ts
```

Choose a new private state path for a new fixture. Provision creates fresh faucet
keys, deploys the pinned Prime/adapter wasm, installs and binds all canonical
policies, and approves only Prime. The prove phase performs both positive supplies,
the SDK exact-boundary rejection and four fully signed enforcing simulations,
then withdraws all supplied assets and revokes the allowance. If a phase is
interrupted, inspect recorded transaction hashes before retrying; run
`PRIME_PROOF_PHASE=cleanup` to withdraw and revoke without repeating the proof.
The verifier re-reads both positive receipts and the cleaned final state.
